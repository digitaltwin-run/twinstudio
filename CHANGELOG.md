# Changelog

## 0.5.0 — 2026-08-12

- Renamed the product and Python package to TwinStudio while retaining a temporary compatibility namespace and `lps` command alias.
- Added the TwinScript 1.0 line-oriented DSL plus canonical YAML/JSON documents.
- Added JSON Schemas, schema index and EBNF grammar.
- Added project-evolution models, controlled action lexicon, bidirectional goal/resource graphs, adjacent-possible exploration, BrainSwarming lineage, mutation, recombination, evaluation and experiment planning.
- Added 34 TwinStudio engineering dimensions and 17 evolution operators.
- Added expanded lifecycle templates and evidence-gated transition records.
- Added REST, CLI, MCP and web UI access to parse, preview, persist and inspect evolution runs.
- Added DOT, Mermaid, JSON, Markdown and CSV evolution artifacts with SHA-256 manifests.
- Expanded MCP from 15 to 21 tools.
- Added DSL/evolution regression tests and updated publication documentation.

## 0.4.0 — 2026-08-11

- Introduced TwinStudio branding and compatibility aliases.
- Added source-grounded feature-lens reviews for design fixation.
- Added REST, CLI, MCP and web feature-lens interfaces.

## 0.3.0 — 2026-08-11

- Added modern MCP 2026-07-28 discovery/tools/resources core with mirrored-header, metadata and Origin validation.
- Retained legacy 2025-11-25 initialization compatibility.
- Expanded lifecycle and publication documentation.

## 0.2.0 — 2026-08-11

- Added product graph and xBOM, scoped 2D/3D selections, typed change plans, CQRS/Event Sourcing, collaboration, simulations and portable project export.
