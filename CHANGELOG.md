## 0.3.0 — 2026-08-11

- Added a modern MCP 2026-07-28 core subset with per-request metadata validation, `server/discover`, required mirror-header checks, cache metadata, `resultType` and Origin validation.
- Kept an explicit legacy `initialize` compatibility path using protocol revision 2025-11-25.
- Expanded MCP tools with human-use and mechanical-rule evaluation.
- Added protocol tests for discovery, modern headers, unsupported versions, Base64 `Mcp-Name`, legacy fallback and Origin rejection.
- Expanded Polish delivery and lifecycle documentation and clarified Open WebUI authentication boundaries.

## 0.2.0 — 2026-08-11

- Added living product object tree and xBOM.
- Added scoped 2D/3D selection evidence and selection resolution.
- Added typed LiteLLM/local natural-language change planner.
- Added CQRS/Event Sourcing, role permissions and email approval onboarding.
- Added POA URI contract, Protobuf DSL, REST/CLI/shell/MQTT/MCP surfaces.
- Added power, thermal, human-use, mechanical and camera sample simulations.
- Added lifecycle, FMEA, test-plan, packaging and ecommerce structures.
- Added optional CadQuery, MQTT gateway, device simulator, Open WebUI and MinIO Compose profiles.
- Added allow-listed selected-region STEP B-Rep edits for directional holes and local-box add/cut, with derived STEP/STL and an auditable operation journal.
- Added PCB/SCH adapter roadmap and KiCad CLI scaffold.
