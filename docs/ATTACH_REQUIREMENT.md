# ATTACH_REQUIREMENT

## Purpose

Propose linking a typed requirement to a selected object.

## Syntax

`kind=attach_requirement; target_uri=<poa>; arguments.requirement_uri=<poa>`

## Inputs

A selected target and a requirement with provenance.

## Outputs

A scoped requirement association for review.

## Errors

Unknown requirement references or missing provenance prevent attachment.

## Examples

Attach a minimum ingress-protection requirement to the enclosure assembly.
