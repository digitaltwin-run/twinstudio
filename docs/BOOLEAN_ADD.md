# BOOLEAN_ADD

## Purpose

Propose additive geometry within the selected scope.

## Syntax

`kind=boolean_add; target_uri=<poa>; arguments.feature_type=<add-type>`

## Inputs

A selected region and typed dimensions for the additive solid.

## Outputs

A deferred additive CAD operation.

## Errors

Unsupported solids, ambiguous placement or collisions prevent automatic realization.

## Examples

Add a scoped reinforcement pad to a selected enclosure wall.
