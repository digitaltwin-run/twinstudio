# ADD_TEST

## Purpose

Propose a verification test for a selected object or change.

## Syntax

`kind=add_test; target_uri=<poa>; arguments.test_type=<type>`

## Inputs

A selected target, test type, acceptance criteria and evidence expectations.

## Outputs

A typed test proposal linked to the product scope.

## Errors

Tests without measurable acceptance criteria remain unresolved.

## Examples

Add a wall-thickness inspection after regenerating the selected enclosure part.
