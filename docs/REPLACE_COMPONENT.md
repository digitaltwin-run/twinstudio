# REPLACE_COMPONENT

## Purpose

Propose replacement of a selected product component.

## Syntax

`kind=replace_component; target_uri=<poa>; arguments.replacement_uri=<poa>`

## Inputs

A selected component and a resolvable replacement candidate.

## Outputs

A reviewed component replacement plan with downstream impact.

## Errors

Missing compatibility evidence or a replacement outside the allowed catalog blocks realization.

## Examples

Replace a selected purchased fastener with an approved catalog equivalent.
